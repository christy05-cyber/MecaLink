
# MecaLink – Connect. Repair. Drive.

## 1. Project Overview

MecaLink is an automotive support platform designed to connect vehicle owners with mechanics, automotive service providers and spare parts sellers.

The website aims to make it easier for users to find assistance when experiencing vehicle breakdowns, access automotive information, locate mechanics and explore vehicle-related products.

MecaLink provides a central platform where users can seek help, share experiences and connect with other members of the automotive community.

**Live Website:**  
https://christy05-cyber.github.io/mecalink/

**GitHub Repository:**  
https://github.com/christy05-cyber/MecaLink

---

## 2. Website Pages and Features

The MecaLink website consists of the following pages:

- **Home:** Introduces the MecaLink platform and its main services.
- **Registration:** Allows users to enter their details through a registration form.
- **Get Help:** Provides information and assistance for vehicle-related problems.
- **Find a Mechanic:** Helps users explore mechanic services.
- **Location:** Provides location-related information.
- **Community:** Gives users a space to connect and share automotive experiences.
- **Marketplace:** Allows users to explore vehicle parts, mechanic tools and automotive products.
- **Ratings and Reviews:** Provides a section for feedback and service reviews.
- **About Us:** Explains the purpose and objectives of MecaLink.
- **Get in Touch:** Allows visitors to contact the MecaLink team.

### 3.2 Responsive Design

Responsive design was implemented to ensure that the website can adapt to different screen sizes and devices.

The following breakpoints were used:

| Device | Breakpoint | Layout |
|---|---|---|
| Desktop | Above 1024px | Multi-column layout |
| Tablet | 768px–1024px | Two-column layout |
| Mobile | Below 768px | Single-column layout |
| Small mobile | Below 480px | Adjusted spacing and font sizes |

### 3.3 Media Queries

CSS media queries were used to adjust the website layout for different screen sizes.

```css
@media screen and (max-width: 1024px) {
    /* Tablet layout adjustments */
}

@media screen and (max-width: 768px) {
    /* Mobile layout adjustments */
}

@media screen and (max-width: 480px) {
    /* Small mobile adjustments */
}
```

## 4. Part 3 Updates – Enhancing Functionality and SEO

Part 3 focused on improving the functionality, usability and search engine optimisation of the MecaLink website.

### 4.1 JavaScript Functionality

JavaScript was added to improve user interaction and make the website more functional.

The implemented features include:

- Registration form submission feedback.
- Contact form submission feedback.
- Marketplace search functionality.
- Marketplace category filtering.
- Interactive navigation between marketplace sections.

### 4.2 HTML Forms and Validation

HTML form validation was implemented to help users enter the required information correctly.

The registration and contact forms include validation features such as:

- Required fields.
- Appropriate input types.
- Email validation.
- Password length requirements where applicable.
- JavaScript confirmation messages after form submission.

These features improve the user experience by providing immediate feedback.

**Note:** The current form confirmation messages are front-end demonstrations. The forms are not connected to a database or email-processing service.

### 4.3 Marketplace Functionality

The marketplace was improved to make it easier for visitors to explore automotive products and categories.

The functionality includes:

- A search field for finding relevant marketplace content.
- Category buttons for Vehicle Parts and Tools & Equipment.
- Navigation to the relevant marketplace sections.
- Improved organisation of marketplace content.

### 4.4 Search Engine Optimisation (SEO)

SEO improvements were made to help search engines understand the content of the website.

The improvements include:

- Descriptive page titles.
- Meta descriptions.
- Relevant page descriptions.
- Clear HTML page structure.

These changes help identify the purpose and content of individual website pages.
